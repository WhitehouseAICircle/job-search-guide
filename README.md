# Whitehouse AI Circle: a job-search Project demo

A practical guide to using a ChatGPT Project to organise a job search: understand job adverts, improve a CV, prepare recruiter messages and practise interviews.

Whitehouse AI Circle is a local community sharing useful, responsible ways to use AI. This demo is for beginners and experienced users alike. You do not need to write code or download this repository: open the guides below and copy the example prompts into ChatGPT.

**Start with fictional information.** This repository is public. Never add a real CV, application, private message or personal screenshot here.

## Start here

1. Read the [privacy notes](docs/privacy-notes.md).
2. Follow the [job-search walkthrough](docs/job-search-workflow.md), including its ready-to-copy fictional example.
3. Copy the [Project instructions](docs/project-instructions.md) into your own Project.
4. Try the [example chats and prompts](docs/example-chats.md).
5. Optionally set up a [daily Job Sweep](docs/job-sweep.md) to shortlist publicly advertised roles.
6. If you use LinkedIn, try the [profile refresh guide](docs/linkedin-profile.md), starting with sharing controls.

Allow around 20–30 minutes for a first try, at your own pace. You will need access to ChatGPT and its Projects feature for the Project steps. If you cannot find it, try the prompts in an ordinary chat, supplying the relevant context each time.

## Why use a Project?

A Project keeps related chats, files and instructions together. For example, you can keep a chat for CV work and another for interview practice around the same job search. Always confirm which role and source material you want used; check important details yourself.

Official background: [OpenAI's Projects guide](https://learn.chatgpt.com/docs/projects), checked on 7 November 2026. Features and menus can change; this guide avoids relying on a particular screen layout.

## Keep yourself in charge

AI can misunderstand an advert or invent convincing details. Check every qualification, date, claim and employer detail. Use it to describe your real experience clearly; never invent experience or submit an answer you cannot explain.

This is a learning resource, not a recruitment service or a promise of employment. You decide what to apply for and what to send.

## Website

Read the guide at [Whitehouse AI Circle job-search guide](https://whitehouseaicircle.github.io/job-search-guide/).

The website is plain HTML, CSS and JavaScript with no visitor accounts, forms or analytics. All guide content and copy controls work locally; copying depends on browser clipboard permissions and has a manual selection fallback.

To update the guide, edit the Markdown in docs/ or images/README.md, install Python Markdown (python -m pip install Markdown) if needed, then run python build_site.py. Commit the generated HTML alongside the source changes. Preview with python -m http.server 8765. GitHub Pages serves the repository root on main; .nojekyll keeps the generated pages unchanged.
